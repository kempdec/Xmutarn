Inputs

Crie seus formulários rapidamente.

Básico

Os input podem ser criado com o uso do prefixo input. Veja como criar um campo de input abaixo.

Exemplo

<div class="input">
   <input class="input--field" placeholder="Default">
</div>

<div class="input">
   <input class="input--field input--field_outlined" placeholder="Outlined">
</div>

Rótulos ativos

Também é possível adicionar pequenos rótulos ativos para seus input. Eles devem vir depois dos campos (.input--field), como no exemplo abaixo.

Exemplo

<div class="input">
    <input class="input--field">
    <label class="input--label input--label_active">
        Default
    </label>
</div>

<div class="input">
    <input class="input--field input--field_outlined">
    <label class="input--label input--label_active">
        Outlined
    </label>
</div>

Descrição

Exemplo

    </p>

<div class="input">
    <input class="input--field input--field_outlined" placeholder="Outlined">

Cores

As cores podem ser usadas pra destacar um input.

Exemplo

Uma descrição de atenção.

Uma descrição de sucesso.

<div class="input input_color-alert">
    <input class="input--field" placeholder="Alert">
</div>

<div class="input input_color-warning">
    <input class="input--field" placeholder="Warning">
    <p class="input--description">
        Uma descrição de atenção.
    </p>
</div>

<div class="input input_color-success">
    <input class="input--field input--field_outlined" placeholder="Success">
    <p class="input--description">
        Uma descrição de sucesso.
    </p>
</div>

Instância a partir do HTML

Você pode criar uma instância simples a partir do HTML com o atributo x-input e obter alguns recursos extras, como um rôtulo que alterna entre ativado e desativado.

Clique dentro do campo para ver a transição.

Exemplo

<div class="input" x-input x-input-label="Default">
    <input class="input--field">
</div>

<div class="input" x-input x-input-label="Outlined">
    <input class="input--field input--field_outlined">
</div>

Instância em ES

Uma instância em EcmaScript pode ser criada, caso queira ter mais controle sobre o componente.

<div id="i-input-example" class="input">
    <input class="input--field">
</div>
const inputElement = document.getElementById("i-input-example");
const input = new X.InputComponent(inputElement);
