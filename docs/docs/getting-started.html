Começando

Saiba como começar a usar o Xmutarn em seus projetos.

Início rápido

Use o CDN de UNPKG em seus projetos para começar a usar o Xmutarn rapidamente.

CSS

<link rel="stylesheet" href="https://unpkg.com/xmutarn@0.29.0-beta/dist/css/xmutarn.min.css">

JS

<script src="https://unpkg.com/xmutarn@0.29.0-beta/dist/js/xmutarn.min.js"></script>

Modelo inicial

Algumas tags são fundamentais para o bom funcionamento do Xmutarn. Segue abaixo um modelo de como começar.

<!DOCTYPE html>
<html lang="pt-br">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1, shrink-to-fit=no">

    <!-- CSS -->
    <link rel="stylesheet" href="https://unpkg.com/xmutarn@0.29.0-beta/dist/css/xmutarn.min.css">
</head>

<body>

    <!-- JS -->
    <script defer src="https://unpkg.com/xmutarn@0.29.0-beta/dist/js/xmutarn.min.js"></script>
</body>

</html>

Instalação

Obtenha o Xmutarn através dos gerenciadores de pacotes NPM e Yarn. Essas versões contém apenas os arquivos de estilo, scripts, notas de lançamento, licença e o leia-me.

Ou faça o download direto do GitHub.

NPM

npm install xmutarn

Yarn

yarn add xmutarn
