Começando

Saiba como começar a usar o Xmutarn em seus projetos.

Instalação

Obtenha o Xmutarn através dos gerenciadores de pacotes NPM e Yarn. Elas são as versões padrões do framework.

Yarn

Esta versão contém apenas os arquivos de estilo, script, notas de lançamento, licença e o leia-me. 

yarn add xmutarn

NPM

Esta versão contém apenas os arquivos de estilo, script, notas de lançamento, licença e o leia-me. 

npm install xmutarn
