Temas

Os temas são o que dão vida a sua página, use temas pré-definidos, ou crie o seu! Todas as classes adotam o prefixo theme-.

Existem três tipos diferentes de temas: O principal, de destaque e de realçe. Assim como o nome sugere, o tema principal é proposto para definir as cores principais dos elementos e textos da página, de destaque para destacar, e de realçe para realçar.

Tema principal

Para definir qual tema será utilizado na página, adicione o atributo x-main-theme no elemento html, com o nome do tema principal. 

<html x-main-theme="light"></html>

Por padrão o Xmutarn tem apenas 2 temas principais disponíveis: light e dark, sendo "light" o padrão.

Clique nos botões abaixo para alternar entres o temas.

As classes adotam o prefixo theme-main-. Assim como as cores, os prefixos fg-, bg- e bd- para textos, fundos e bordas são utilizados. Use o prefixo theme-main-fg- (foreground) para textos, theme-main-bg- (background) para fundos e theme-main-bd- (border) para bordas.

Exemplo

Texto com a cor "primary" do tema principal.

Texto com a cor "secundary" do tema principal.

Texto com a cor de fundo "disabled" do tema principal.

Elemento com a cor de fundo "card" e borda da cor "dividers" do tema principal.

</p>

As classes de temas também tem a possibilidade de seu uso com pseudo-classes e pseudo-elementos.

Caso queira criar seu próprio tema, é possível criando um estilo CSS semelhante com o abaixo. Sendo "example" o nome do tema e as variáveis CSS com suas respectivas cores. 

html[x-main-theme="example"] {
  --theme-main-primary: rgba(0, 0, 0, .87);
  --theme-main-secondary: rgba(0, 0, 0, .54);
  --theme-main-hint: rgba(0, 0, 0, .38);
  --theme-main-disabled: rgba(0, 0, 0, .38);
  --theme-main-dividers: rgba(0, 0, 0, .12);
  --theme-main-background: #FAFAFA;
  --theme-main-card: white;
}

Também é possível mesclando o nosso mapa SASS: 

// Seu mapa (exemplo).
$your-theme-map: (
  example: (
    primary: rgba(0, 0, 0, .87),
    secondary: rgba(0, 0, 0, .54),
    hint: rgba(0, 0, 0, .38),
    disabled: rgba(0, 0, 0, .38),
    dividers: rgba(0, 0, 0, .12),
    background: get-palette-color($color-name: grey, $color-hue: 50),
    card: white
  )
);

// Mescla o nosso mapa `$themes-main-properties` com seu mapa `$your-theme-map` (exemplo).
map-merge($map1: $themes-main-properties, $map2: $your-theme-map);

Ou até mesmo sobrescrever nosso mapa SASS, porém este método impedira que utilize nossos temas pré-definidos. Use este método apenas se realmente deseja ter este resultado. 

// Define as propriedades dos temas principais.
$themes-main-properties: (
  example: (
    primary: rgba(0, 0, 0, .87),
    secondary: rgba(0, 0, 0, .54),
    hint: rgba(0, 0, 0, .38),
    disabled: rgba(0, 0, 0, .38),
    dividers: rgba(0, 0, 0, .12),
    background: get-palette-color($color-name: grey, $color-hue: 50),
    card: white
  )
);
