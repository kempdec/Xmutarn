Cores

Dê mais vida as suas páginas com as cores do Xmutarn.

Uso

As cores da paleta são separadas pelo primeiro plano (foreground) e plano de fundo (background). Ambos os planos tem seus respectivos prefixos e podem ser aplicados na sua página facilmente

Primeiro plano

Para aplicar cores em textos, use o prefixo fg-.

Este é um cartão com um parágrafo em roxo.

<div class="card">
    <p class="card--content fg-purple">
        Este é um cartão com um parágrafo em roxo.
    </div>
</div>

Plano de fundo

Para aplicar um plano de fundo, use o prefixo bg-.

Este é um cartão com o plano de fundo roxo.
<div class="card padding-md fg-white bg-purple">
    Este é um cartão com um plano de fundo roxo.
</div>
