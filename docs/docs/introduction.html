Iniciando sem dificuldades

O Xmutarn adota um padrão que tem como objetivo facilitar o desenvolvimento dos projetos, decorando alguns prefixos, você já pode começar a criar suas páginas.

Prefixos

Nós acreditamos que cada vez mais os desenvolvedores buscam pela produtividade. Pensando nisso, usamos prefixos para facilitar e agilizar a codificação, descartando a necessidade de consultar a documentação do framework com frequência.

Com a ajuda do IntelliSense e o prefixo certo, é possível listar todas as opções de estilo. Isso é útil para quem esqueceu o nome daquela classe, mas sabe seu prefixo ou até para listar as variações, descendentes, filhos e outros da mesma.
