Iniciando sem dificuldades

O Xmutarn adota um padrão que tem como objetivo facilitar o desenvolvimento dos projetos, decorando alguns prefixos, você já pode começar a criar suas páginas.

Prefixos

Nós acreditamos que cada vez mais os desenvolvedores buscam pela produtividade. Pensando nisso, usamos prefixos para facilitar e agilizar a codificação, descartando a necessidade de consultar a documentação do framework com frequência.

Com a ajuda do IntelliSense e o prefixo certo, é possível listar todas as opções de estilo. Isso é útil para quem esqueceu o nome daquela classe, mas sabe seu prefixo ou até para listar as variações, descendentes, filhos e outros da mesma.

Padrões de nomeação

O padrão de nomeação de classes CSS do Xmutarn, batizado de CSSCNP, define algumas regras sobre como as classes do framework devem ser nomeadas.

Isso ajuda no momento da codificação, ciente do padrão é possível facilmente saber onde a classe pode ser aplicada.

Conheça mais sobre o CSSCNP.

Variantes

As classes variantes herdam o nome da sua classe alvo e são separadas por um underscore (_).

Exemplo do uso de uma variante da barra de navegação que aplica a cor preta na mesma:

<div class="toolbar toolbar_dark-color"></div>

Classe alvo: toolbar
Classe variante: toolbar_dark-color

Descendentes

As classes descendentes herdam o nome da sua classe pai e são separadas por dois traços (--).

Em outras palavras, quando uma classe contém dois traços (--) indica que ela é descendente de outra.

<div class="toolbar">
    <nav class="toolbar--nav"></nav>

    <nav class="toolbar--nav">
        <a class="toolbar--nav--item">Item</a>
    </nav>
